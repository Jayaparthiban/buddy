# Jayaparthiban T - Personal Portfolio

A modern, responsive portfolio website showcasing the skills, projects, and achievements of **Jayaparthiban T**, a Computer Science with Cognitive Systems student.

## 🚀 Features
- **Modern Design**: Clean, professional layout with blue, white, and soft gray color scheme
- **Responsive**: Fully responsive design that works on desktop, tablet, and mobile devices
- **Smooth Animations**: Elegant hover effects and scroll-triggered animations
- **Interactive Elements**: Mobile-friendly navigation, smooth scrolling, and form validation
- **Professional Sections**: About, Skills, Projects, Experience, Achievements, and Contact

## 📁 File Structure
```
portfolio/
├── index.html          # Main HTML file
├── styles.css          # CSS styles and responsive design
├── script.js           # JavaScript for interactivity
└── README.md           # This file
```

## 🎨 Customization Guide

### Personal Information
Update the following in `index.html`:
- **Name and Title**: Update the hero section with your name and tagline
- **About Section**: Modify the personal story and background
- **Contact Information**: Update email, social media links, and contact details
- **University Name**: Replace `[Your University]` with your actual university

### Skills Section
Add or modify skills in the skills grid:
- **Technical skills** with appropriate Font Awesome icons
- **Soft skills** with relevant icons
- Update skill categories as needed

### Projects
Customize the projects section:
- Add your actual project descriptions
- Update project images/icons
- Modify project tags to match your technologies
- Add links to live demos or GitHub repositories

### Experience & Certifications
Update with your actual:
- Internship details and dates
- Certification information
- Company names and roles

### Achievements
Modify to include your:
- Academic achievements
- Awards and recognitions
- Leadership roles
- Publications

## 🚀 Deployment

### Option 1: GitHub Pages
1. Create a new repository on GitHub
2. Upload all files to the repository
3. Go to Settings > Pages
4. Select source branch (usually `main`)
5. Your site will be available at `https://username.github.io/repository-name`

### Option 2: Netlify
1. Create a Netlify account
2. Drag and drop the `portfolio` folder to Netlify
3. Your site will be deployed instantly
4. Customize the URL in site settings

### Option 3: Vercel
1. Create a Vercel account
2. Import your GitHub repository
3. Deploy with one click
4. Get a custom domain option

## 🔧 Customization Tips

### Adding Your Photo
- Replace the profile placeholder in the hero section
- Add your image to the project folder (e.g., `assets/profile.jpg`)
- Update the HTML to use your image instead of the icon

### Changing Colors
1. Open `styles.css`
2. Find the color variables at the top
3. Update the hex values to match your preferred color scheme

### Adding New Sections
1. Copy an existing section structure from `index.html`
2. Add corresponding CSS styles in `styles.css`
3. Update navigation links

### Custom Animations
- Add CSS animations in `styles.css`
- Use JavaScript in `script.js` for interactive animations
- Test on different devices for performance
